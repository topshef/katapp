1 · Where we are

Desktop: chart top-left, Orders | Transactions columns.

Mobile: orders + transactions stacked.

The honest read: everything a trader needs is present, but it's presented as diagnostic output, not as a market. The cards are sentences of monospace ("0.0.2154537 USDC 0.014784 → 0.0.2154537 KGBP 0.011") where the account id — the least decision-relevant token — is visually the loudest. Side (buy/sell) is a word inside italic prose instead of a colour signal. Glyph clusters (△ ⇄ 🏦 ⏳ ❓) carry real meaning but no legend or hierarchy. The chart floats without axes, last price, or a header; the pair selector is a small underlined link. Numbers don't align, so nothing can be compared by scanning down a column.
What's already right: maker avatars + 🔷/△ reputation marks (a genuine differentiator — no exchange shows counterparty reputation), red/green tx edge, relative timestamps, the new ✍ auto-sign pill, the hide-expired/only-mine filters, and green/red buy/sell in the chart bars.

2 · Principles (what regular traders expect)

  • Price is the hero. Every order row leads with price; size second; everything else recedes. Traders scan a price column, not sentences.
  • Side is a colour + badge, never prose. Green BUY / red SELL, always in the same position.
  • Monospace is for numerals only. Use font-variant-numeric: tabular-nums on numbers inside a proportional UI font. Full-monospace prose is what makes the current cards read as logs.
  • Alignment beats labels. A column of right-aligned prices with aligned decimals needs no "price:" label.
  • Accounts are identity chrome, not content. Avatar + short id + 🔷 in small type; full id on tap (the player modal is now the home for that).
  • Status is a chip in a fixed corner — open / partial / filled / expired / ✍ requested / ✍ signed — one vocabulary everywhere, same colours as the signing glow (green settled, orange pending, red failed).

  • Book view: when "sort by price" is on, collapse cards to one-line rows (side · price · size · fill%) — cards for browsing, rows for the ladder. Same DOM, a density toggle.

6 · Chart pass

  • Keep the SVG, give it axes: price gridlines + labels on the right (exchange convention), time ticks below.
  • Explain the encodings or drop them: solid green/red = filled buys/sells is good; the dashed outlines (open orders?) need either a two-item legend or removal. One unexplained encoding costs more trust than it adds information.
  • Add a last-price horizontal line tied to the header number, and my-order markers (small ▸ at my prices) — the two overlays traders actually use.
  • Hover/touch crosshair with price+time readout. Candles/depth chart are later luxuries; axes + last-price line are the 80%.

7 · Layout

  • Desktop: header strip full-width → chart left (bigger, ~60%) with the metrics beside it → below: Orders (book) left | Transactions right, as now but with the new cards. Messages dock right (ORDER-CHATDOCK1) when it lands.
  • Mobile: header strip → chart (collapsible) → tabs Book · Mine · Trades instead of stacked accordions — tabs keep one list on screen with its filters, which is how every mobile exchange resolves this space.
  • The + / − order buttons become a single prominent “＋ New order” button in the header strip (side chosen inside the modal); − (remove account) moved to the account row per KAT-ACCTNORM1's "management lives in the profile".
