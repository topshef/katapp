## **Katomia Sandbox - Initial Scoping Phase**

The aim of this short phase is to get you comfortably up to speed with the **core concepts, tools, and ecosystem** behind the project, without going too deep too quickly. By the end, you should have a working understanding of how the system operates and be in a position to decide which areas are most interesting to explore further.

This is intentionally practical and exploratory — part onboarding, part discovery — and gives us a chance to align on where your interests (from MORSE) overlap with the project.

---

### **Tasks**

**1. Basic setup**

- Create a GitHub account (if not already)

- Install HashPack Wallet and create a Hedera testnet account

- Safely store keys and understand basic wallet usage

---

**2. Core concepts (light study)**  
Get familiar with:

- Public / private key cryptography (signing, verification basics)

- How Hedera Hashgraph works at a high level:
  
  - Accounts vs keys (separation, multi-key control)
  
  - Transaction signing and consensus
  
  - Fast finality vs traditional blockchains

👉 Suggested interactive resource:

- Brilliant (good short courses on cryptography, logic, and probability)

---

**3. Hands-on system interaction**

- Use a test environment to:
  
  - Create simple “orders” (basic asset exchanges)
  
  - Fill or respond to orders

- Treat this as a **sandbox/game** to understand:
  
  - how multi-party trades work
  
  - how flows between accounts are structured

---

**4. Light technical awareness (optional, not deep)**

- Skim basics of:
  
  - WebSockets (real-time messaging)
  
  - Simple Node.js backend concepts  
    *(no need to code yet — just awareness)*

---

**5. Checkpoint / validation**

- Complete a short quiz (multiple choice + simple scenarios) covering:
  
  - keys vs accounts
  
  - transaction flow
  
  - basic system mechanics

- Quick discussion to review:
  
  - what made sense
  
  - what areas felt interesting

---

## **Outcome**

By the end of this phase, you should:

- Understand the **foundations of the platform and Hedera**

- Be comfortable interacting with the system at a basic level

- Have a clearer idea of how your MORSE studies could apply (e.g. optimisation, modelling, strategy)

From there, we can define a **more focused project or experiment** aligned with your interests.

---

**TLDR**

Objective is to get you familiar with the core concepts and tools, and assess potential alignment with your MORSE studies.

**Scope:**

- Set up GitHub (if needed)
- Create a wallet using HashPack Wallet (testnet)
- Learn key basics:
  - public/private keys
  - transaction signing
  - multi-signature (threshold key) concepts
- High-level understanding of Hedera Hashgraph:
  - accounts vs keys
  - fast finality
- Light hands-on interaction with a simple test environment
- Short quiz + review discussion at the end

Outcome is simply to get you to a point where you understand the foundations and we can identify areas for a more focused follow-on project.
