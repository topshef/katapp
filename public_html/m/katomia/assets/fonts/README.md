# Fonts

`felt-digits.woff2` — **Atkinson Hyperlegible Mono, Bold**, the ten digits only (1.4 KB, Google
Fonts `text=0123456789` subset). Used by FELT-NUMBER1 for the account number set into the felt
(`katomia-board.js` `ringFeltNumber`, `@font-face KatFeltDigits` in `katomia-board.css`). Chosen
because it was designed for low-vision reading: 0, 6, 8 and 9 stay distinct at a glance.
