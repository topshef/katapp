# Best simple alert flow

For a transaction alert, don’t show five equal buttons. That will feel scary.

Use a two-layer pattern:

## First screen: simple decision

```text
🔔 Tim has a transaction ready

KEA checked the package:
✅ Tim signed this order
✅ Amounts match the order
✅ Network: mainnet
✅ Expires in 42 seconds

Approve this transaction?
```

Primary buttons:

```text
✅ Approve once
👀 Review details
```

Secondary / quieter options:

```text
Not now
```

Danger menu:

```text
More…
```

# “More…” menu options

Put the heavier options behind **More**, not on the main alert.

```text
✅ Approve once
🔁 Approve matching transactions for 1 hour
♾️ Always approve this watch
⏸️ Pause this watch
🚫 Block this watch
🗑️ Delete this watch
```

That split matters.

**Approve once** is an action.  
**Always approve** is a policy change.  
**Delete** is setup management.  
They should not all sit at the same level.

# Recommended button wording

I’d use:

## Safe default

```text
Approve once
```

Better than “Approve now”, because “once” reassures the user that they are not granting permanent authority.

## Temporary trust

```text
Approve for 1 hour
```

or:

```text
Trust this for 1 hour
```

## Permanent policy

```text
Always approve matching transactions
```

Not just “Approve always”, because “matching” is the important safety word.

## Rejection

```text
Reject this transaction
```

Use this when KEA sends a signal back.

## Ignore

```text
Not now
```

Use this when KEA simply does nothing.

## Block

```text
Never approve this watch
```

or stronger:

```text
Block this trader key
```

## Delete

```text
Delete watch
```

Only for removing the watch from KEA.

# Important distinction

You probably want four different “no” actions:

| UX action                   | Meaning                      |
| --------------------------- | ---------------------------- |
| **Not now**                 | Do nothing; maybe it expires |
| **Reject this transaction** | Send a refusal signal back   |
| **Pause watch**             | Stop alerts temporarily      |
| **Block / Delete watch**    | Stop trusting this source    |

That distinction is future-proof, but the first MVP can hide most of it.
