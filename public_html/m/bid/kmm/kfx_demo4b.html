KFX — Generic multi-asset intent clearing (cycle-based demo)

Participants declare hyperedges (multi-asset bundles with a scale). The solver finds clearing cycles (length 2 or 3) and executes them greedily.

Edit JSON below and click Solve

Notes: this demo clears only through cycles, so every executed bundle is atomically balanced per-asset. Wants do not affect solving (reporting only). Objective: B — maximise total weighted output (native units).

        Model summary
        
State
  - Participants i
  - Assets a (with decimals)
  - Net deltas Δ[i][a]

Clearing
  For each asset a:  Σ_i Δ[i][a] = 0

Intents
  For each participant, intents are hyperEdges:
    inputs  { assetId: amount, ... }
    outputs { assetId: amount, ... }
    scale x in [minScale, maxScale]

Execution primitive
  Execute a cycle (length 2 or 3) with a single common scale x.
  Feasible only if each step’s inputs can be supplied by previous step’s outputs.

Objective
  Maximise total weighted output: Σ (participantWeight * sum(outputs) * x)
