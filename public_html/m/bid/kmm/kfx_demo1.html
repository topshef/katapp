KFX LP (Piecewise Offers) — standalone demo

This models the LP as a fractional knapsack over piecewise segments. Optional maxParties is handled with a simple heuristic pre-filter.

Edit the JSON in the textarea and click Solve

Offer segments are interpreted as: for each segment you may allocate up to inMax units of input asset, producing amountOut = amountIn * rate * (1 - feeBps/10000).

        LP formulation (what we’re solving)
        
Decision variables
  x_{i,k} ≥ 0   input allocated to party i, segment k

Parameters
  cap_{i,k}     segment capacity (max input allowed)
  r_{i,k}       segment exchange rate (buy per 1 unit sell), net of fee if you want
  Q             total input Bob wants to sell
  K             max parties allowed (optional)

Constraints
  (1) Fill constraint:     Σ_i Σ_k x_{i,k} = Q
  (2) Segment caps:        0 ≤ x_{i,k} ≤ cap_{i,k}
  (3) Clearing is implicit in settlement object: Bob’s -Q equals others’ +Q on the sell asset

Objective (best execution for Bob)
  maximize:  Σ_i Σ_k (r_{i,k} * x_{i,k})

Notes
  - With only (1)(2), this LP is solved by taking highest r_{i,k} segments first (greedy)
  - With a party limit K, add binary y_i and constraints x_{i,k} ≤ cap_{i,k} y_i, Σ_i y_i ≤ K
    That becomes a small MILP; here we use a heuristic pre-filter to keep it MVP-simple
