KFX — Clearing demo (LP, soft receiveMin)

Choose execution scales x_e for participant hyperEdges (recipes) such that global clearing holds (Σ deltas per asset = 0) while minimizing total unmet receiveMin via slack variables.

Input JSON schema 
{
  "assets": [ { "id": "USDC", "decimals": 2 }, ... ],

  "participants": [
    {
      "id": "Alice",
      "weight": 1,

      "wants": {
        "receiveMin": { "assetId": "HBAR", "amount": 900 } // optional; soft
      },

      "hyperEdges": [
        {
          "inputs":  { "USDC": 1 },
          "outputs": { "HBAR": 10 },
          "minScale": 0,       // optional, default 0
          "maxScale": 100      // required, >0
        }
      ]
    }
  ]
}
Math spec 
Variables
  - For each hyperEdge e: x_e
  - For each participant i with wants.receiveMin: slack s_i >= 0

Per-edge delta:
  Δ_e(a) = x_e * (outputs_e[a] - inputs_e[a])

Per-participant delta:
  Δ_i(a) = Σ_{e in E_i} Δ_e(a)

Clearing:
  For each asset a: Σ_i Δ_i(a) = 0

Bounds:
  minScale_e <= x_e <= maxScale_e

Soft receiveMin:
  Δ_i(r) + s_i >= R_i

Objective:
  minimize Σ_i (weight_i * s_i)
